What Is a Function?

"A system that takes in an input, performs an operation, and gives out an output. Think of it as a black box—you don't need to know HOW it works inside every time you use it, just WHAT it does."

The Black Box Concept

Abstraction in action: Once add(a, b) is defined, you can call it anywhere without rewriting its internal steps!
Two Parts of Every Function:
  • Function Header (def): The function's name and its parameters (input slots)
  • Function Body & return: The indented instructions that execute and hand back a result

def function_name(parameter1, parameter2):
    # Function body - the code that runs when called
    result = parameter1 + parameter2
    return result  # Hand the output back to the caller

# Calling the function with arguments (2, 3)
output = function_name(2, 3)  # output = 5

Abstraction

# Define function once
def calculate_grade(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"
    else:
        return "F"

# Reuse it anywhere in your program
grade1 = calculate_grade(95)  # "A"
grade2 = calculate_grade(82)  # "B"
grade3 = calculate_grade(68)  # "F"
