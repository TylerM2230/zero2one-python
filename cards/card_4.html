PITFALL WATCH The Critical Pitfall: Catching input() Inside a Variable + Explore
Common Mistake: Calling input() without assigning it to a variable is like asking someone their name and immediately forgetting it! 
# [AVOID]  — The user's answer is never stored and vanishes immediately!
input("Enter your name: ")
print(name)  # NameError: name 'name' is not defined

# [GOOD]  — Catch the user's response inside a variable box!
name = input("Enter your name: ")
print("Hello, " + name)
TYPE RULE Remember: input() Always Returns a String! + Explore
"Even if a user types digits like 25 into input(), Python receives it as the text string '25'. To do math with it, wrap it in int()." 
# 1. input() always gives you a string (text)
raw_age = input("Enter your age: ")   # User types 25 → raw_age is "25" (str)

# 2. Cast to int so you can do arithmetic
age = int(raw_age)                    # age is now 25 (int)
next_year = age + 1                   # 26 (int)

# 3. Cast back to str if gluing into a sentence with +
print("Next year you will be " + str(next_year))
