Why Can't We Treat All Information the Same?

"There are different kinds of information in the world, and Python must know which kind is inside a box before it knows how to act on it."

The Three Fundamental Types

String (str)

Text & Characters

"Hello World"

Anything wrapped in quotes. Even "25" in quotes is treated as text, not a quantity!

Integer (int)

Whole Numbers

42

Whole numbers without quotes or decimals. Ready for arithmetic: +, -, *, /.

Boolean (bool)

Truth Switch

True / False

Only two possible values: True or False. Powers every decision in code.

# Inspect any value's type using type()
type("hello")   # <class 'str'>
type(42)        # <class 'int'>
type(True)      # <class 'bool'>

# Convert between types explicitly
age_num = int("25")              # "25" (str) -> 25 (int)
msg = "Score: " + str(100)       # 100 (int)  -> "100" (str)
